## 我在做什么

我目前在 **云享智慧（徐汇滨江）** 做 AI 产品、Agent 研发与 FDE。工作现场主要是零售与电商：让 VLM 看懂商品，让搜索从关键词框长成智能导购，让多模态 Agent 生产真正可用的品牌内容，也让运营流程能够每天稳定地自己跑起来。

过去半年，我主导或核心参与了 6 个企业级 AI 项目：

- 将多品牌 VLM 商品标签服务推进为生产常驻系统，内部验收准确率持续 **95%+**，标签直接影响 ZARA 中国官网搜索商品标签。
- 为 IKEA、Wacoal、ZARA、UNIQLO 搭建商品组合图与模特图工作流。
- 独立完成 [UNIQLO AI-native Search H5](https://new-search-h5.pages.dev/)，把传统召回、LightRAG、KG/SDP 证据与对话式 Agent 筛选融进同一个导购体验。
- 主导 [SkuGEO](https://skugeo.com/) 的产品闭环：URL 解析、问题诊断、内容生成、多平台发布、AI 问答监测与 before/after 分析。
- 将搜索运营中的巡检、查询、诊断与飞书汇报封装成每日稳定运行的 Agent 产品。

> 我也把求职当作双向选择：先保持自己的 Ownership、审美和创造速度，再去寻找真正欣赏这种工作方式的人。

## 我反复回到的问题

- Agent 到底有没有真正节省人的时间，而不只是把工作换一种方式重新做一遍？
- 多模态模型怎样进入生产流程，而不是停在一张偶然好看的 Demo？
- 搜索、知识图谱、RAG 与 Agent 能否共同形成新的零售交互，而不是在旧产品旁边加一个聊天框？
- 个人与团队每天产生的知识，怎样继续变成内容、产品和可累积的认知资产？
- 多 Agent 协作增加的协调成本，什么时候值得，什么时候不值得？
